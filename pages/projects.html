SISTEMA DE CONTROLE E MONITORAMENTO DE IRRIGAÇÃO

Desenvolvimento de um sistema de controle e monitoramento de irrigação utilizando NodeMCU ESP8266, com automação baseada em níveis ajustáveis de umidade do solo e monitoramento remoto via aplicativo ou página web. O sistema integra irrigação por gotejamento, energia fotovoltaica e comunicação com servidor web, promovendo eficiência hídrica e energética. Voltado à Agricultura Familiar, oferece uma solução sustentável e acessível para otimizar a produtividade agrícola.

SISTEMA DE IRRIGAÇÃO INTELIGENTE COM MONITORAMENTO REMOTO DE VARIÁVEIS

Desenvolvimento de um sistema de irrigação inteligente com automação baseada na umidade do solo, monitoramento remoto via dashboard online e comunicação de longa distância com tecnologia LoRa, ideal para áreas sem acesso à internet. O sistema utiliza o NodeMCU ESP8266 para gerenciar variáveis como consumo de água, temperatura do solo e nível do reservatório, promovendo economia hídrica, eficiência agrícola e disponibilidade de dados para análise.

HAVEN CAFETERIA

O projeto Cafeteria Haven é um site desenvolvido com HTML e CSS, hospedado no GitHub Pages. Seu objetivo é apresentar uma cafeteria fictícia em um ambiente virtual acolhedor e visualmente refinado, inspirado no estilo do seriado FRIENDS. O design busca transmitir uma sensação de aconchego, sofisticação e nostalgia através do uso de cores quentes e elementos visuais retrôs.
