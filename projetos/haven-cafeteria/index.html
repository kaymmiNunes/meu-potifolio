Haven Cafeteria

Acessar o site

Site expositivo desenvolvido com HTML e CSS para apresentar uma cafeteria fictícia em um ambiente virtual acolhedor, visualmente refinado e inspirado no estilo do seriado FRIENDS.

Objetivos do projeto

  • Criar uma página institucional para uma cafeteria fictícia.
  • Trabalhar identidade visual, cores, tipografia e organização de conteúdo.
  • Praticar estruturação semântica com HTML e estilização com CSS.
  • Publicar o projeto em ambiente web para demonstração no portfólio.

Tecnologias e conceitos aplicados

  • HTML5
  • CSS3
  • Responsividade
  • Design visual
  • GitHub Pages

Este projeto faz parte do meu portfólio por demonstrar aplicação prática de tecnologia na solução de problemas reais, integrando planejamento, desenvolvimento e análise de impacto.
