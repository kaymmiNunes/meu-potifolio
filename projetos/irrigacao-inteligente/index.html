Sistema de Irrigação Inteligente com Monitoramento Remoto de Variáveis

Projeto de irrigação inteligente com automação baseada na umidade do solo, monitoramento remoto por dashboard online e comunicação de longa distância com tecnologia LoRa, pensado para áreas rurais com baixa disponibilidade de internet.

Objetivos do projeto

  • Monitorar variáveis agrícolas relevantes para o controle da irrigação.
  • Utilizar comunicação de longa distância para ambientes rurais.
  • Organizar dados para análise e tomada de decisão.
  • Promover eficiência hídrica e melhor acompanhamento da produção.

Tecnologias e conceitos aplicados

  • NodeMCU ESP8266
  • LoRa
  • Dashboard web
  • Sensores
  • HTML
  • CSS
  • JavaScript
  • IoT

Este projeto faz parte do meu portfólio por demonstrar aplicação prática de tecnologia na solução de problemas reais, integrando planejamento, desenvolvimento e análise de impacto.
