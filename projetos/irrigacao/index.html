Sistema de Controle e Monitoramento de Irrigação

Projeto voltado ao desenvolvimento de um sistema de controle e monitoramento de irrigação utilizando NodeMCU ESP8266, automação baseada na umidade do solo, comunicação com servidor web, irrigação por gotejamento e possibilidade de uso com energia fotovoltaica.

Objetivos do projeto

  • Automatizar o processo de irrigação com base na umidade do solo.
  • Reduzir desperdício de água em pequenas produções agrícolas.
  • Permitir monitoramento remoto das informações do sistema.
  • Aplicar conceitos de sustentabilidade, automação e sistemas embarcados.

Tecnologias e conceitos aplicados

  • NodeMCU ESP8266
  • Sensores de umidade
  • HTML
  • CSS
  • JavaScript
  • Automação
  • Sistemas embarcados

Este projeto faz parte do meu portfólio por demonstrar aplicação prática de tecnologia na solução de problemas reais, integrando planejamento, desenvolvimento e análise de impacto.
